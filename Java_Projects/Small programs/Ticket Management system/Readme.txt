A Java-based movie ticket management system that determines ticket eligibility and pricing based on customer category. The system validates whether a customer qualifies as AARP, Adult, Child, Military, or Senior, demonstrating conditional logic, object-oriented design, and real-world business rules in Java.

 Features

Categorizes customers as:

AARP

Adult

Child

Military

Senior

Automatically checks eligibility based on age or status

Assigns correct ticket type based on user input

Prevents invalid ticket selections

Clean, readable Java logic using conditionals and OOP principles

🛠 Technologies Used

Java

Object-Oriented Programming (OOP)

Conditional logic (if / else)

Console-based input/output (if applicable)
