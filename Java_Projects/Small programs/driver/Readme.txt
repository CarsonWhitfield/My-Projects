📋 Java Linked List Menu Application

This project is a menu-driven Java application that implements a custom singly linked list from scratch. Users can interact with the list through a console-based menu to add, remove, display, or clear elements.

   Overview

The program consists of three main components:

  DriverLab5 – The driver class that presents a menu, processes user input, and controls program flow.

  Node – Represents an individual node in the linked list, storing a student name and a reference to the next node.

  linkedList – Implements the core linked list logic, including insertion, deletion, traversal, and list management.

   Features

  Insert elements at the end of the list

  Print all elements in the list

  Delete an element at a specified position

  Clear the entire list

  Exit the program through menu selection

  Tracks list size dynamically

    Technical Highlights

      Custom Data Structure

      Manual implementation of a singly linked list

      Object-Oriented Design

      Separate classes for driver logic, nodes, and list operations

      User Input Handling

      Console-based interaction using Scanner

  Control Flow

    Menu-driven loop using switch statements

    Pointer Manipulation

    Explicit handling of node references (next pointers)

   Program Flow

    The menu is displayed repeatedly until the user exits

    User selects an option to manipulate the linked list

    Operations are performed based on the user’s choice

    The list updates dynamically after each operation
