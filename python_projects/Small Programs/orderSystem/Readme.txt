☕ Coffee Shop Ordering System (Python)

This Python program simulates a simple coffee shop ordering system using a menu-driven, text-based interface. Customers can place multiple drink orders, and the program calculates and displays the final total.

🔹 What It Does

Displays a coffee menu with item prices

Uses a dictionary to store drink names and prices

Allows users to:

Add multiple drinks to their order

Continue ordering until they enter "no"

Keeps track of:

Items ordered

Total cost of the order

Prints a numbered order summary and total price at checkout

🔹 How It Works

The menu is printed at the start of the program

User inputs drink names (case-insensitive)

Valid items are added to the order list and total price

Invalid items prompt the user to try again

Once ordering ends, the program prints the full order and total

🔹 Concepts Demonstrated

Dictionaries for price lookup

Lists for tracking orders

Loops and conditionals

User input handling and validation

Simple aggregation (running totals)
