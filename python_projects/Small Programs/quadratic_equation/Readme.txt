📐 Quadratic Equation Solver (Python)

This Python program generates a random quadratic equation and computes its real roots using the quadratic formula. It demonstrates mathematical computation, user input handling, and formatted output.

🔹 What It Does

Randomly generates:

An integer coefficient a between 1 and 10

A floating-point coefficient b between 0 and 10

Prompts the user to enter a value for c

Ensures c is treated as a negative value for the calculation

Applies the quadratic formula to compute two solutions

Prints the equation and its roots

🔹 Key Function

quadratic_equation(a, b, c2)

Calculates the discriminant (b² − 4ac)

Computes and prints the two solutions for x

🔹 Concepts Demonstrated

Random number generation (random.randint, random.uniform)

Mathematical operations using math.sqrt

User input validation and adjustment

Function-based program structure

Numeric formatting for readable output
